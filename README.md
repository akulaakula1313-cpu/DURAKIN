# Дурак — SANI GROUP Premium Edition

Онлайн «Подкидной дурак» на Node.js + Socket.IO с премиальным интерфейсом.
Версия 2.1.0 — исправлены правила игры, ротация ролей и безопасность.

## Быстрый старт

```bash
npm install
npm start
# Открыть http://localhost:3000
```

Переменные окружения:

| Переменная     | По умолчанию | Описание                                  |
|----------------|--------------|-------------------------------------------|
| `PORT`         | `3000`       | порт HTTP-сервера                         |
| `CORS_ORIGIN`  | `*`          | разрешённый origin для Socket.IO          |

## Структура

```
server.js          вся игровая логика и Socket.IO
public/index.html  клиент (раздаётся статикой; исходники сервера наружу не уходят)
test/game.test.js  регрессионные тесты правил
test/deep.test.js  полные партии ботов с проверкой инвариантов
test/simulation.js баланс сложностей ботов
```

## Тесты

```bash
npm test          # правила: 14 проверок
npm run test:deep # 540 партий ботов, инварианты на каждом шаге
npm run simulate  # статистика поражений по сложностям
```

## Правила, которые реализует сервер

* Колода 36 карт, козырь лежит на дне и выдаётся последним.
* Первым ходит игрок с младшим козырем; если козырей нет — случайный.
* Подкидывать можно только достоинства, уже лежащие на столе.
* На столе максимум 6 пар, и неотбитых карт не больше, чем карт на руке у защитника.
* Добор до 6 карт: первым добирает открывший кон, защитник — последним.
* «БИТО» → атакует бывший защитник. «БЕРУ» → защитник пропускает ход, атакует следующий за ним.
* Игрок, оставшийся без карт при пустой колоде, выходит из игры и больше не получает ролей.
* Игра заканчивается только между конами; последний с картами — дурак, пустые руки у всех — ничья.
* Если 40 конов подряд заканчиваются взятием, объявляется ничья (защита от вечной партии).

## Что изменилось в 2.1.0

1. Козырная карта больше не уходит из колоды первой (раздача и добор — с одного конца).
2. Конец игры не объявляется, пока кон не доигран: защитник всегда успевает отбиться.
3. Вышедшие из игры игроки исключаются из ротации и не могут «взять» карты обратно.
4. Лимит подкидывания считается по неотбитым картам, а не по числу пар.
5. Клиенту больше не отправляется содержимое колоды — только её размер.
6. Боты не зависают после неверного хода игрока; убран бесконечный цикл подкидывания.
7. Добор идёт в правильном порядке, защитник — последний.
8. Реконнект: постоянный `pid` в localStorage, 60 секунд на возвращение в партию.
9. Лимит времени хода 60 сек с авто-ходом — зависший игрок больше не блокирует стол.
10. `public/` вместо раздачи всей папки, анти-спам чата и эмодзи, проверка прав на реванш.
11. Игра с ботами 1×1, 1×2 или 1×3; тасовка через `crypto.randomInt`.
