# SANI GROUP • ДУРАК — FIXED

Исправлена критическая ошибка повторного `БЕРУ`: повторный клик больше не добавляет одни и те же карты в руку несколько раз.

Также клиент теперь:
- скрывает `БЕРУ` после принятия карт;
- корректно показывает фазу после `БЕРУ`;
- разрешает корректное подкидывание после `БЕРУ`;
- не показывает `БИТО`, когда стол ещё не отбился;
- защищает действия от двойного клика;
- автоматически скрывает козырную карту после её фактического добора из колоды.

Сервер:
- авторитетная проверка ходов;
- 36 уникальных карт;
- 2–4 игрока;
- серверный таймер;
- боты;
- комнаты и reconnect;
- rematch;
- anti-cheat проверки;
- `/health`.

Запуск:

```bash
npm install
npm start
```

Проверка:

```bash
npm test
npm run test:deep
npm run simulate
```
