# Дурак — SANI GROUP Premium Edition

Онлайн-игра в «Подкидного дурака» с бэкендом на Node.js + Socket.io и красивым премиальным интерфейсом.

## 🚀 Быстрый запуск

```bash
# 1. Установите Node.js (https://nodejs.org) — версия 18+
# 2. В папке проекта:
npm install
# 3. Запустите сервер
npm start
# 4. Откройте в браузере: http://localhost:3000
```

## 🎮 Как играть

### Режимы
- **🤖 Играть с ботом** — быстрый матч 1 на 1 против ИИ
- **🌐 Создать комнату** — стол на 2–4 реальных игроков (пришлите код другу)
- **ВХОД В КОМНАТУ** — введите 6-значный код и нажмите «ВОЙТИ»

### Управление
- **Клик по карте** — сыграть её (если ход разрешен)
- **БЕРУ** — взять все карты со стола (только защищающийся)
- **БИТО** — завершить атаку (все карты отбиты, говорит атакующий)
- **ПАС** — передать право подкидывания следующему атакующему

### Правила (кратко)
1. Колода 36 карт, по 6 карт каждому. Последняя карта колоды — козырь.
2. Первым ходит игрок с младшим козырем.
3. Атакуют картами тех же достоинств, что уже на столе.
4. Отбиваться можно старшей картой той же масти или козырём. Козырь бьёт только старший козырь.
5. После бито/взятия — добирание до 6 карт. Когда колода кончилась — игра до последней карты.
6. Проигравший — у кого остались карты в конце.

## ⚙️ Особенности реализации

- **Авторитативный сервер** — вся игровая логика на бэкенде, клиент только рендерит
- **Боты играют по правилам** — выбирают минимально подходящую карту, не тратят козыри зря
- **Чистый код** — нет неиспользуемых переменных, единый стиль, модульные функции
- **Адаптивный UI** — работает на ПК и мобильных
- **Реванш** — голосование всех людей в комнате перед рестартом
