# SANI GROUP — Дурак Premium

Исправленная версия «Подкидного дурака» на Node.js + Express + Socket.IO.

## Что исправлено
- Авторитетная серверная логика партии: клиент не может сам решить, какая карта разрешена.
- Полная колода 36 карт, уникальные карты, козырь и первый ход.
- Правильная проверка отбоя: масть/старшинство/козырь.
- Подкидывание только по достоинствам карт на столе.
- Ограничение подкидывания: максимум 6 карт и не больше руки защищающегося.
- `БЕРУ`, завершение подкидывания, добор до 6.
- Поддержка 2–4 игроков.
- Боты с тремя уровнями сложности.
- Серверный таймер хода 30 секунд.
- Реванш только после завершения партии; в онлайн-режиме нужен голос каждого подключённого человека.
- Проверка членства в комнате для всех действий.
- Защита от отправки чужих карт: сопернику передаются только рубашки/количество карт.
- Ограничение чата и whitelist эмодзи.
- Комнаты с уникальным 4-значным кодом и автоматическим закрытием.
- Краткая grace-сессия для восстановления соединения после временного разрыва.
- `/health` для Render/мониторинга.

## Запуск

```bash
npm install
npm start
```

Открыть `http://localhost:3000`.
