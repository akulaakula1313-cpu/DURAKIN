# Дурак — SANI GROUP Premium Edition

Онлайн «Подкидной дурак» на Node.js + Socket.IO с премиальным интерфейсом.

## Быстрый старт

```bash
npm install
npm start
```

Открыть `http://localhost:3000`.

## Проверка логики

```bash
npm test
```

Тесты проверяют 36-карточную колоду, раздачу, уникальность карт, переход хода после «БЕРУ», отсутствие зацикливания `ПАС` и полные симуляции игр для 2/3/4 игроков.
